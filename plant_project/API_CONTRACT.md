# Контракт API распознавания растений (версия 1.0)

Этот документ — единственный источник правды для обоих участников.
Меняется только по договорённости обоих, с повышением версии.

## Общие правила

- Базовый адрес: `http://<IP-компьютера>:8000`
- Формат ответов: JSON, кодировка UTF-8
- Все поля называются в `snake_case`
- `confidence` — число от 0 до 1 (не проценты)
- Предсказания отсортированы по убыванию `confidence`
- Размер файла: не более 10 МБ; форматы: JPEG, PNG, WEBP
- Рекомендация для приложения: перед отправкой уменьшить фото до 1024 px по длинной стороне

## Эндпоинты

### GET /health

Проверка связи. Ответ `200`:

```json
{ "status": "ok", "model_loaded": true, "api_version": "1.0", "model_version": "stub-0.1" }
```

### GET /classes

Список всех классов, которые знает модель. Ответ `200`:

```json
{
  "count": 5,
  "classes": [
    { "id": 0, "label": "Rosa canina", "name_ru": "Шиповник собачий" }
  ]
}
```

### POST /predict

Запрос: `multipart/form-data`, поле **`file`** — изображение.
Необязательный query-параметр `top_k` (1..10, по умолчанию 5).

Ответ `200`:

```json
{
  "predictions": [
    { "class_id": 0, "label": "Rosa canina", "name_ru": "Шиповник собачий", "confidence": 0.91 },
    { "class_id": 3, "label": "Bellis perennis", "name_ru": "Маргаритка многолетняя", "confidence": 0.05 }
  ],
  "inference_ms": 87,
  "model_version": "stub-0.1"
}
```

## Ошибки

Любая ошибка возвращается в одном формате:

```json
{ "error": { "code": "invalid_image", "message": "Файл не является изображением" } }
```

| HTTP | code | Когда |
|---|---|---|
| 400 | `invalid_image` | файл не открывается как изображение |
| 400 | `missing_file` | нет поля `file` |
| 413 | `file_too_large` | больше 10 МБ |
| 415 | `unsupported_type` | не JPEG/PNG/WEBP |
| 422 | `invalid_params` | неверный `top_k` |
| 500 | `internal_error` | сбой сервера |
| 503 | `model_not_ready` | модель не загружена |

## Список классов

- Файл `classes.json` лежит в репозитории и используется и сервером, и приложением (для справочника).
- **Порядок в файле = порядок выходов модели**: класс с `id = 0` это нулевой выход сети.
- Менять порядок или состав после начала обучения нельзя без переобучения.
- `label` — латинское название (уникальное), `name_ru` — русское.

## Быстрая проверка (curl)

```
curl http://localhost:8000/health
curl http://localhost:8000/classes
curl -F "file=@rose.jpg" "http://localhost:8000/predict?top_k=3"
```

## Особенности для приложения

- Эмулятор Android: адрес `http://10.0.2.2:8000`
- Реальный телефон: `http://<IP ПК в сети>:8000`
- Android блокирует HTTP без шифрования: включить `usesCleartextTraffic="true"`
- Если `predictions[0].confidence < 0.5`, показывать «Не уверен, попробуйте другое фото»
